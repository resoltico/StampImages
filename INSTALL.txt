STAMP IMAGES 1.2.1 - SHORTCUTS INSTALLATION

Source, releases and build attestation:

    https://github.com/resoltico/StampImages

Requirements
============

macOS 12.3 or later, Shortcuts, and Homebrew runtime tools:

    brew install exiftool vips

Node is not a runtime dependency. Typefaces come from the macOS font system.

Download and verify
===================

Download Stamp-Images.jxa, SHA256SUMS, INSTALL.txt and LICENSE from the release.
With the GitHub CLI installed, run these commands in the download folder:

    gh attestation verify Stamp-Images.jxa --repo resoltico/StampImages
    gh attestation verify SHA256SUMS --repo resoltico/StampImages
    gh attestation verify INSTALL.txt --repo resoltico/StampImages
    gh attestation verify LICENSE --repo resoltico/StampImages
    shasum --check SHA256SUMS

The checksum manifest covers the JXA artifact; each downloaded file has its own
build attestation. A local source build has no GitHub release attestation.

Install the Quick Action
========================

1. Open Shortcuts and create a shortcut.
2. Open its details, enable "Use as Quick Action", and enable Finder.
3. Configure it to receive Files from Finder.
4. Add "Run JavaScript for Mac Automation".
5. Replace the example code with the complete contents of Stamp-Images.jxa.
   From a source checkout, use dist/Stamp-Images.jxa.
6. Name the shortcut "Stamp Images".

Use it
======

Select image files or folders in Finder and run Stamp Images. Selected folders
are searched recursively; copies go into the selected folder, including copies
of images in its subfolders. Directly selected images get copies beside them.
Overlapping selections process each source once. Originals are not modified.

Review selection problems, choose settings, and click Create. The date is on
by default and GPS is off. Appearance settings, including GPS, are remembered;
custom text is not. Turning GPS off changes only the visible stamp: embedded
location metadata remains in the copy.

The progress panel offers Stop, which acts at the next safe checkpoint. Saved
copies are kept. A finished unpublished copy is retained in its workspace and
its path reported, without starting a Downloads access request. Completion
reports saved and recovered paths, unfinished work and metadata omissions.

Failed saves attempt recovery to Downloads, then a confirmed temporary copy.
If recovery fails, the workspace is retained. Copy retained work somewhere
permanent promptly: system temporary storage can be cleared by macOS.

For supported formats and selection rules, see README.md in the source
repository. HEADLESS.md specifies noninteractive settings and JSON receipts.

Remove it
=========

1. Delete the Stamp Images shortcut in Shortcuts.
2. To forget its remembered appearance settings, run:

       defaults delete com.resoltico.StampImages

The preferences domain holds appearance settings, never custom text or photo
records. A message that the domain does not exist means there are no settings
to remove. Normal working files are removed when a run ends. Finished retained
copies and uncertain workspaces require attention at their reported locations;
inspect and save needed work before removing those files. Saved outputs and
Downloads recovery copies remain until you remove them yourself.

exiftool and vips are independently installed tools. If nothing else needs them,
you can remove them with:

    brew uninstall exiftool vips
