STAMP IMAGES 2.0.0 - SHORTCUTS INSTALLATION

Source, releases and build attestation:

    https://github.com/resoltico/StampImages

Requirements
============

macOS 12.3 or later, with Shortcuts. The Quick Action needs no Node.js runtime.
Install its command-line tools in Terminal:

    brew install exiftool vips

vipsheader comes with vips. Typefaces come from the macOS font system.

Verify a download
=================

The release workflow attests the JXA, checksum manifest, installation
instructions and license. With GitHub CLI installed, from the download folder:

    gh attestation verify Stamp-Images.jxa --repo resoltico/StampImages
    shasum --check SHA256SUMS

Install the Quick Action
========================

1. Open Shortcuts and create a new shortcut.
2. In its details, enable "Use as Quick Action" and Finder.
3. Configure it to receive Files from Finder.
4. Add "Run JavaScript for Mac Automation".
5. Replace the example code with the COMPLETE contents of the downloaded
   Stamp-Images.jxa. In a repository checkout, that file is at
   dist/Stamp-Images.jxa.
6. Name the shortcut "Stamp Images".

To install a newer build, replace the complete pasted script. Download
checksums do not verify an installed pasted copy.

Use it
======

Select images or folders in Finder and run Stamp Images. Review any items that
cannot be included, choose the settings, then click Create. Copies of images
found in a selected folder are saved in that folder; copies of images selected
directly are saved beside them, as name_stamped.jpg. Originals are never
modified. Ultra HDR JPEG photos produce standard-range JPEG copies without
gain maps; capture metadata and color profiles are retained.

Turning GPS off changes only what the stamp shows: every copy keeps the
location metadata its original carries.

If a copy cannot be saved where it belongs, it is saved to Downloads, or
failing that to a temporary copy, and completion shows where. Move recovered
work somewhere permanent promptly: macOS can clear temporary storage.

README.md in the repository describes the settings, supported images and
output in full. HEADLESS.md describes command-line use.

Remove it
=========

1. Delete the "Stamp Images" shortcut in Shortcuts.
2. To forget the remembered appearance settings, run:

       defaults delete com.resoltico.StampImages

The preference domain stores appearance settings only, never custom text. A
message that the domain does not exist means there is nothing to remove.
Working files are normally cleaned up; inspect any recovery or workspace
location a run reported before removing it. Your images and their stamped
copies stay until you remove them.

exiftool and vips may be used by other software. If nothing needs them, remove:

    brew uninstall exiftool vips
