STAMP IMAGES 1.1.0 - SHORTCUTS INSTALLATION

Source, releases and build attestation:

    https://github.com/resoltico/StampImages

Verifying what you downloaded
=============================

Every file in the release is signed with a GitHub build attestation. With the
GitHub CLI installed, from the folder you downloaded them into:

    gh attestation verify "Stamp-Images.jxa" \
        --repo resoltico/StampImages
    shasum --check SHA256SUMS

Requirements
============

macOS 12.3 or later.

The Shortcuts app is macOS 12 and later; 12.3 is the point at which its
JavaScript engine supports everything this action uses.

Runtime tools
=============

Open Terminal and run:

    brew install exiftool vips

Nothing else has to be installed. Typefaces are read from the font system
macOS already provides.

Install the Quick Action
========================

1. Open the Shortcuts app.
2. Create a new shortcut.
3. Open the shortcut details.
4. Enable "Use as Quick Action".
5. Enable Finder.
6. Configure the shortcut to receive Files from Finder.
7. Add "Run JavaScript for Mac Automation".
8. Delete the example code in that action.
9. Paste the complete contents of:

       dist/Stamp-Images.jxa

10. Save the shortcut as "Stamp Images".

Use it
======

Select image files or folders in Finder and run the Quick Action. Selected
folders are searched recursively. Each image gets a stamped copy, saved in
each folder you selected or beside each image you selected; the original
files are not changed.

The date is on by default and GPS coordinates are off. Turning GPS on adds the
place the photograph was taken to the stamp, and the choice is remembered for
the next run. Leaving it off does not remove location data already in the
image.

Review any selection problems, choose the settings, and click Create. With
stepwise dialogs, the last dialog confirms the settings before files are
created. Completion reports the copies saved and anything not stamped.

Remove it
=========

1. In the Shortcuts app, delete the "Stamp Images" shortcut.
2. To forget the settings it remembered, open Terminal and run:

       defaults delete com.resoltico.StampImages

That is everything it leaves on your Mac. It keeps one preferences entry,
under that name, holding the settings of your last run -- never the text you
typed, and nothing about your photographs. Its working files go in the system
temporary folder and are cleared away as each run ends; a run that could not
save a finished copy leaves them in place on purpose, and the message says
where they are.

exiftool and vips are yours rather than this action's, and anything else on
your Mac may be using them, so they are left alone. Remove them with

    brew uninstall exiftool vips

if nothing else needs them.
